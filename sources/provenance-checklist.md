# Provenance Checklist

Use this before making the repo public or linking it from the manifesto.

## Hard Rules

- No tokenized Proof links.
- No Slack links.
- No private Notion or Drive links.
- No private GitHub links.
- No raw customer/support data.
- No raw finance data.
- No unapproved employee examples.
- No exact benchmark scores without source packet review.

## Required Checks

- Secret scan.
- Search for `token=`.
- Search for `proofeditor.ai/d/`.
- Search for `slack.com/archives`.
- Search for `notion.so`.
- Search for `docs.google.com`.
- Search for customer emails and ticket IDs.
- Review final Git diff.
- If a private repo was used for drafting, publish through a clean sanitized release branch or clean repo.

## Claim Checks

- Senior Engineer benchmark has prompt, model/version/date, task packet, rubric, evaluator method, human baseline, and caveats.
- Fin/Waqqas case study has support/editorial approval for any metrics or specifics.
- Every internal workflow examples have approval from the relevant owner.
- Public links resolve.
- Any "needs provenance" claim is either caveated or omitted.
