This repo is the companion kit for Dan Shipper's manifesto, **The Tide Is Rising**. It is designed for a human and an agent to use together: read the essay, copy a prompt, point your agent at the files here, and use the material to understand, challenge, and apply the argument.

## How To Use This With An Agent

1. Open the essay and this repo side by side.
2. Copy one prompt from [`prompts/starter-prompts.md`](prompts/starter-prompts.md).
3. Give your agent any relevant non-sensitive context about your work.
4. Ask it to use [`claims.md`](claims.md) as the claim map and [`research-index.md`](research-index.md) as the source guide.
5. Push back. The point is not to accept the essay. The point is to think with it.

Use non-sensitive summaries when giving context to your agent. Do not paste confidential company docs, private customer information, internal links, financial data, or personnel details unless you are using a tool approved for that data.

## What This Repo Is For

This repo answers four practical questions:

- **What should I believe?** See [`claims.md`](claims.md).
- **What should I do?** See [`prompts/starter-prompts.md`](prompts/starter-prompts.md).
- **What can I copy?** See [`AGENTS.md`](AGENTS.md) and the prompt pack.
- **Where did this claim come from?** See [`research-index.md`](research-index.md) and [`sources/public-sources.md`](sources/public-sources.md).

## What This Repo Is Not

This is not a full bibliography, a chatbot, or a mirror of the essay. It is a working packet for agent-assisted reading. Some internal Every examples are summarized as public-safe case studies rather than linked to raw private materials.
